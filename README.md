---

## 📖 What is JavaScript?

**JavaScript** is a programming language used to add **logic, behavior, and interactivity** to websites and web applications.

It allows us to work with webpages, user interactions, data, APIs, asynchronous operations, and much more.

---

## 🗺️ Roadmap

My JavaScript learning path is divided into the following areas:

### **01 · Fundamentals**

Variables, Data Types, Operators, Type Conversion, Input & Output

### **02 · Control Flow**

Conditions, `if / else`, `switch`, `for`, `while`, `do...while`

### **03 · Core JavaScript**

Strings, Arrays, Functions, Objects, Methods, Scope

### **04 · Modern JavaScript**

ES6+, Arrow Functions, Destructuring, Spread & Rest, Modules

### **05 · DOM & Events**

DOM Manipulation, Elements, Attributes, Styles, Event Handling, Event Listeners

### **06 · Advanced JavaScript**

Closures, Hoisting, Execution Context, `this`, Prototypes, `call / apply / bind`

### **07 · Asynchronous JavaScript**

Callbacks, Promises, `async / await`, Error Handling

### **08 · APIs & Data**

JSON, `fetch()`, HTTP, GET / POST, API Integration

### **09 · Projects**

Practice Programs, Logic Building, DOM Projects, API Projects, Real-World Applications

### **10 · Beyond JavaScript**

Node.js, npm, Express.js, Backend Development, Full-Stack Development
